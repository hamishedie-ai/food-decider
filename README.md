# Food Decider 🍽️

A tiny quiz for a very big question: *what do you want to eat?*

Pick breakfast, lunch or dinner, answer a few questions (hunger, craving, vibe, cuisine), and get either:

- **A place around Hobart** that does it, with address, a Maps link and a price guide, or
- **A short shopping list and recipe** to cook it together at home.

It's a single `index.html` with no build step. Open it in a browser, or turn on GitHub Pages (Settings → Pages → Deploy from branch → `main` / root) to get a link.

Restaurant picks come from Hobart food guides. Check opening hours before you head out.
